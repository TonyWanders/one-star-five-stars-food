A program that writes one alien tourist's one-star review of Earth to
`/output/entry.txt`, for the make.fun competition
[One Star, Five Stars for the Food](https://make.fun/bounty/u-po-pu-one-star-five-stars-for-the-food-f9166ee7).

Run it with Python 3:

```
python3 main.py
```

It writes the review below to `/output/entry.txt` (or to the path given as
the first argument, or `$OUTPUT_PATH`). No network, no clock, no
randomness. The review is one sentence of 160 characters, inside the 1 to
200 gate.

## The review

```
One star: your gravity broke my luggage, your weather changed its mind twice, and the locals kept asking about my probe, but the tacos were worth the abduction.
```
